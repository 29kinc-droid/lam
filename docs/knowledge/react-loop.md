# ReAct 루프란

ReAct(Reasoning + Acting)는 LLM이 추론과 행동(툴 호출)을 번갈아 수행하며 문제를 해결하는 패턴이다. 이 프로젝트의 루프는 다음과 같이 동작한다.

1. 사용자 입력을 대화 이력에 추가한다.
2. LLM을 호출한다. 응답이 툴 호출이면 3번으로, 아니면 5번으로 간다.
3. 요청된 툴을 실행하고 결과를 대화 이력에 추가한다.
4. 2번으로 돌아간다. 단, `max_rounds`(현재 5회)를 넘으면 중단한다.
5. 최종 텍스트 응답을 사용자에게 반환하고, 상태(Redis)와 에피소드(Postgres)에 기록한다.
